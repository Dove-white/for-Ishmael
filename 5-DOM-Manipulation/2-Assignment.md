# 🧩 DOM Practice Project — Interactive Task Manager

This project will help you practice the DOM by building a small interactive application using:

* DOM selection
* Event listeners
* Creating elements dynamically
* Removing elements
* Updating content
* Working with classes
* Handling user input

By the end, you will understand how JavaScript interacts with a webpage in real-world applications.

---

# 🚀 What You’re Building

You will build a simple **Task Manager App**.

Users will be able to:

✅ Add tasks
✅ Delete tasks
✅ Mark tasks as completed
✅ See live updates on the page
